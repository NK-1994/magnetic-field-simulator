# 直線電流がつくる磁場 シミュレーター

直線電流のまわりで方位磁針を動かし、その場所の磁場の向きと強さ $H$ を読み取るシミュレーターです。
距離 $r$ と磁場の強さ $H$ を記録してグラフにし、$H$ が $1/r$ に比例することを確かめられます。

- 公開ページ：https://nk-1994.github.io/magnetic-field-simulator/
- パソコン・タブレット・スマートフォンのブラウザで動きます。外部のライブラリは使っていません（HTMLファイル1つで完結）。

## 前提
- 無限に長い直線電流を仮定し、$H = I/(2\pi r)$ で計算しています。
- 地磁気は考慮していません。
- これはシミュレーションです。実測データではありません。
